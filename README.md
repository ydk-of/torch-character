# Торч — постоянное хранилище персонажа

- [`character.json`](character.json) — полный набор сведений всех 12 разделов листа: числовые показатели, плюшки, структурированные таблицы, заметки и исходная HTML-разметка каждого раздела для без потерь.
- [`character.html`](character.html) — исходный визуальный лист с тёмной темой, кнопками и раскрываемыми блоками.
- [`CHANGELOG.md`](CHANGELOG.md) — журнал изменений.

## Согласованность

`character.json` является основным источником данных. На момент миграции разделы JSON сверены с `character.html` посимвольно (содержимое каждого раздела). При новых изменениях обновлять оба файла и журнал изменений одним логическим обновлением, затем перечитывать их из GitHub.

## Текущая особенность формата

Таблицы и заметки доступны структурированно; сложные описания, списки, карточки и форматирование дополнительно хранятся в `sections[].html`. **Автоматический генератор HTML из JSON пока не реализован.** Изменения должны поддерживать обе версии согласованными.

## Публикация GitHub Pages

В корне репозитория размещён `index.html` — полная копия `character.html` для GitHub Pages. При изменениях листа синхронно обновлять `character.json`, `character.html`, `index.html` и `CHANGELOG.md`. Для стандартной публичной публикации: сделать репозиторий публичным, затем в Settings → Pages выбрать Deploy from a branch, `main`, `/(root)` и Save. Включение Pages выполняется владельцем в настройках GitHub.
