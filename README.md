# Торч — лист персонажа

Хранилище персонажа настольной ролевой кампании.

- [character.html](character.html) — полный лист Торча: состояние, навыки, плюшки, снаряжение, заклинания, отношения и исследования. **Основной полный источник данных.**
- [character.json](character.json) — структурированные характеристики, ресурсы и плюшки для автоматизации; остальные сведения пока хранятся в HTML.
- [CHANGELOG.md](CHANGELOG.md) — журнал изменений.

При каждом изменении обновлять `character.html`, синхронизировать затронутые поля `character.json`, дополнять `CHANGELOG.md` и проверять сохранение повторным чтением через GitHub. Не использовать временные файлы как единственный источник.
